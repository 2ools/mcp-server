# Security policy

## Supported surface

This repository publishes 2ools MCP discovery metadata and documentation. The
hosted MCP endpoint is `https://2ools.app/mcp`. Report vulnerabilities in either
surface privately; do not disclose them in a public issue, pull request, or
discussion.

## Report a vulnerability

Email **2ools.build@gmail.com** with:

- the affected URL, manifest field, tool, or documentation claim;
- reproduction steps and expected versus actual behavior;
- impact and any proof-of-concept that avoids real customer data; and
- a safe way to contact you.

Please do not send credentials, OAuth tokens, payment data, or customer content.
We will acknowledge the report, investigate it, and coordinate a fix and
disclosure timeline with you.

## Scope examples

Examples include incorrect OAuth or scope documentation, an unsafe MCP tool
contract, leaked secret material, or a security flaw in the hosted endpoint.
General product questions and feature requests belong in the product support
channels, not security reports.
